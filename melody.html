MIDI に書き起こす。

音声ファイル・YouTube の共有リンク・URL・再生中のタブの音・マイクから曲を読み込み、主旋律を検出して MIDI ファイルにします。解析はすべてブラウザの中で行われます。

File / ファイル

ここに音声ファイルをドロップ またはクリックして選択（mp3 / wav / m4a / ogg / flac / 動画ファイルなど）

URL

YouTube の共有リンク、または音声ファイルへの直接リンクに対応しています。そのほかの配信サイトは下の「タブの音を取り込む」を使ってください。

Capture / 取り込み

「タブの音を取り込む」は、別のタブで再生している曲をそのまま録音します（PC の Chrome / Edge。共有ダイアログで「タブの音声も共有」をオンに）。

YouTube

ボタンを押すと共有の確認が出るので、「このタブ」を選び「タブの音声も共有」をオンにして許可してください。動画を最初から再生しながら音を取り込み、終わると自動で解析します（曲の長さと同じ時間がかかります。PC の Chrome / Edge）。

曲を読み込むと、自動でメロディの解析が始まります。

About

このツールについて

しくみ

曲の倍音構造から「いちばん目立つ音の高さ」を時間ごとに求め、なめらかにつながる経路を主旋律として選び、半音単位のノートに区切ります。

書き出される MIDI は 1 トラック・単音（モノフォニック）です。

精度について

  • 歌やリード楽器がはっきり聞こえる曲ほどうまく取れます。伴奏が厚い曲では、伴奏の音を拾ったりオクターブがずれたりすることがあります。
  • ベースを拾うときは音域の下限を上げ、歌が途切れるときは感度を上げてみてください。
  • テンポは自動推定です。ずれている場合は BPM を直してから保存してください（ノートの位置は実際の時間のまま書き出されます）。

データの扱い

読み込んだ音声の解析も MIDI の作成も、すべてお使いのブラウザの中で行われます。音声がサーバーに送信されることはありません（URL 読み込みは、そのURLからブラウザが直接取得します。YouTube は公式の埋め込みプレーヤーで再生し、その音をブラウザ内で録音します）。

利用上の注意

他人の楽曲から書き起こしたメロディには、元の曲の著作権が及びます。耳コピの補助や練習など、権利の範囲内でお使いください。

MIDI: フォーマット1・480PPQ・1トラック。解析は 22.05kHz に変換して行います。長い曲は先頭 10 分までを解析します。
